# Incident INC-104

## Title

Checkout latency spike after retry-wrapper deploy

## Service

checkout-api

## Root Cause

A DB retry wrapper amplified load during a brief connection pool exhaustion, causing p95 latency to jump approximately 5x.

## Resolution

The deployment was rolled back.

The later permanent fix involved:

- Exponential backoff
- Circuit breaker

## Investigation Pattern

Relevant signals included:

- Checkout API latency increase
- Database connection pool exhaustion
- Database retry activity
- DB write timeouts
- Recent retry-wrapper deployment

## Relevance

When investigating a new checkout-api latency incident involving database retries or connection-pool exhaustion, compare the current evidence against this incident.
